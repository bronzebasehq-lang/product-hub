Install CleanTake

Current status: no public installer yet

CleanTake is in private testing — there is no downloadable installer today. This page documents what the install will look like so you know exactly what to expect. Join the waitlist and we'll email you once when the first build ships.

Planned: Windows

  • OS: Windows 10/11, 64-bit (first release).
  • What you get: a small desktop app — drag a file in, get a clean file out. No account, no sign-in.
  • Size: TBD — published here before release, not guessed.
  • Requirements: a regular CPU is enough; no GPU needed.

What we will never do

  • No bundled toolbars, no "express install" tricks.
  • No account required to use it.
  • No phoning home — processing stays on your machine (privacy).

macOS / Linux

Not planned for the first release. The engine itself is cross-platform, so ports are possible — tell us on the waitlist which OS you need and it shapes the roadmap.

Last updated: 2026-09-29. We update this page the day an installer actually exists — not before.
