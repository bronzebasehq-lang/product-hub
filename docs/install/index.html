Install CleanTake

v1.0.1 is out — download it now

The first public build shipped 2026-10-02. Two options for Windows 10/11 (64-bit), both free:

Download v1.0.1

Install steps (Windows)

  1. On the release page, grab CleanTake-Setup-1.0.1.exe (one-click installer) or CleanTake-Portable-1.0.1.zip (no install — unzip and run).
  2. If Windows shows "Windows protected your PC" (SmartScreen): click More info → Run anyway. This is expected — the build is unsigned open-source software, not a virus.
  3. The app opens in your browser at http://127.0.0.1:5057. Pick a preset, drop your files in, hit "Clean them".
  4. No account, no sign-in, no GPU needed — a regular CPU is enough.

What we will never do

  • No bundled toolbars, no "express install" tricks.
  • No account required to use it.
  • No phoning home — processing stays on your machine (privacy).

macOS / Linux

Not available yet. The engine itself is cross-platform, so ports are possible — follow the GitHub repo for future builds.
