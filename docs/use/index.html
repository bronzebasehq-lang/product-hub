How to use CleanTake

The whole philosophy: one file in, one file out. No timelines, no projects, no settings maze.

01

Drop a file in

Drag & drop a WAV or MP3 of already-recorded speech — a podcast take, a voiceover, a lecture recording.

02

It cleans locally

Steady room noise (fan, AC, hum) is removed on your machine. Nothing is uploaded anywhere.

03

Take the file out

A loudness-normalized clean file lands next to your input, ready to publish or edit further.

What happens under the hood

input.wav ──▶ ffmpeg ──▶ DeepFilterNet ──▶ loudnorm ──▶ output.wav
              decode      denoise (local)      normalize
  • ffmpeg decodes your input to a clean PCM stream.
  • DeepFilterNet (open source — credited, not claimed as ours) removes steady environmental noise.
  • loudnorm brings the result to a consistent loudness so it sounds right next to other audio.

Good inputs

  • Single speaker, recorded indoors, with steady background noise (fan, AC, hum).
  • WAV or MP3, any reasonable length.

Bad inputs

  • Multiple people talking over each other — CleanTake can't separate voices (limits).
  • Live audio — there's no real-time mode; it processes files.
  • Music or heavily distorted recordings — it's tuned for speech.
