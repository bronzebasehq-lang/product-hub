The waitlist is dead — v1.0.1 is out

By Bronze · October 7, 2026 · 2 min read

On October 2, CleanTake v1.0.1 shipped: a one-click Windows installer and a portable ZIP, free, on the GitHub releases page.

If you visited this site any time between then and today, you wouldn't have known. The install docs still said "there is no downloadable installer today — join the waitlist." The waitlist form was still up. The nav button pointed at it.

That's on me. I shipped the release and forgot the oldest rule: docs are code. They drift from reality the moment you stop treating them like code. For five days this site told visitors a download didn't exist while it sat one click away.

Today that's fixed. Nine pages updated, every waitlist CTA replaced with a real download button, and /docs/install/ rewritten with actual install steps — including the Windows SmartScreen "More info → Run anyway" step, because the build isn't code-signed yet and I'd rather tell you than let you wonder. The old /waitlist/ URL now just says the waitlist is closed and points at the download, so no old link breaks.

What's actually in v1.0.1: CleanTake-Setup-1.0.1.exe (one click) or CleanTake-Portable-1.0.1.zip (unzip and run, no install). The app runs locally at 127.0.0.1:5057 — drop a file, pick a preset, get clean audio back. Fan and AC hum gone (noise floor −33dB → −59dB on our test clip), voice untouched. Same honest limits as always: it will not separate voices in a crowded café.

Download v1.0.1 — free

If you joined the waitlist: there's nothing to wait for anymore. The download button is the whole list now.
