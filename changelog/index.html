Changelog

What shipped, what broke, what's next. Newest first.

v1.0.1 latest

2026-10-02

  • First public release. Two Windows 10/11 (64-bit) downloads on the release page: CleanTake-Setup-1.0.1.exe (one-click installer) and CleanTake-Portable-1.0.1.zip (unzip and run, no install).
  • SmartScreen note: the build is unsigned open source — Windows shows "Windows protected your PC". Click More info → Run anyway. Full source is on GitHub if you'd rather build it yourself.
  • Runs locally: the app opens at http://127.0.0.1:5057 — pick a preset, drop files in, get clean audio out. No account, nothing uploaded.

Install guide: docs → install.

v0.1.0 private testing

2026-09-28

  • Built the MVP pipeline: ffmpeg → DeepFilterNet → loudness normalization, with a local drag-and-drop web UI.
  • Real-voice test passed: steady environmental noise (fan/AC-type hum): noise floor −33dB → −59dB, voice preserved. Hear the samples.
  • Documented a hard limit: 4 overlapping voices in a café-style mix could not be separated — engine reduces voices and noise evenly. Kept as a public limit on the limits page, not hidden.

Known issues: no public installer yet (shipped in v1.0.1); batch mode not built; Windows only for first release.

Up next

  • Batch mode — denoise a folder of files in one go.
  • "Room noise" preset tuned from real user samples.

We only announce a feature here after it actually works — never before.
