v0.1.0 private testing

2026-09-28

  • Built the MVP pipeline: ffmpeg → DeepFilterNet → loudness normalization, with a local drag-and-drop web UI.
  • Real-voice test passed: steady environmental noise (fan/AC-type hum) reduced by ≈ 32 dB, voice preserved. Hear the samples.
  • Documented a hard limit: 4 overlapping voices in a café-style mix could not be separated — engine reduces voices and noise evenly. Kept as a public limit on the limits page, not hidden.

Known issues: no public installer yet; batch mode not built; Windows only for first release.

Up next

  • Batch mode — denoise a folder of files in one go.
  • "Room noise" preset tuned from real user samples.
  • Windows installer (no admin rights needed).

We only announce a feature here after it actually works — never before.
